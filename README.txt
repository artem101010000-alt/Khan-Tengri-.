ХАН-ТЕНГРИ — демо-сайт

Структура:
  index.html   — страницы и тексты
  style.css    — оформление
  script.js    — меню (массив MENU), анимации, мобильное меню
  favicon.svg  — иконка
  images/      — сюда положить logo.png (логотип)

Как открыть: двойной клик по index.html (нужен интернет — фото и шрифты подгружаются).
Как показать заказчику: загрузить папку на Netlify Drop (app.netlify.com/drop) или GitHub Pages — получится ссылка.
